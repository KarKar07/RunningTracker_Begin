# RunningTracker_Begin 🏃

Начальная версия Android-приложения **«Runner» — беговой трекер**.

## Возможности на данный момент

| Экран | Что есть сейчас |
|-------|-----------------|
| **Главный** (`MainActivity`) | Кнопки «Начать пробежку», «История», «Статистика», «Настройки», а также пункт «Настройки» в меню |
| **Пробежка** (`TrackingActivity`) | Секундомер (`Chronometer`) и кнопка Старт/Стоп; поле дистанции в формате `0.00 км` |
| **Результат** (`ResultActivity`) | Показывает дистанцию и время завершённой пробежки |
| **История** (`HistoryActivity`) | Список пробежек на `RecyclerView` |
| **Статистика** (`StatsActivity`) | Переключение периодов «Неделя / Месяц / Год» через `Fragment` |
| **Настройки** (`SettingsActivity`) | Выбор единиц измерения: километры или мили |

## Что ещё не реализовано
- Определение дистанции (GPS / геолокация, запрос разрешений)
- Хранение пробежек (например, Room или SQLite) и загрузка истории из хранилища
- Расчёт и отображение статистики за неделю, месяц и год
-  Отображение маршрута на карте
- Темп, пауза, уведомления во время пробежки

## Технологии

- **Язык:** Java 11
- **Платформа:** Android (`minSdk` 24, `targetSdk` 36)
- **Сборка:** Gradle, Kotlin DSL
- **Библиотеки:** AppCompat, Material Components, ConstraintLayout, RecyclerView, Fragments
- **Тесты:** JUnit, Espresso


## Структура проекта

```
RunningTracker_Begin/
├── app/
│   └── src/main/
│       ├── java/com/example/runner/

│       │   ├── TrackingActivity.java   # секундомер пробежки

│       │   ├── SettingsActivity.java   # настройки единиц измерения
│       │   └── run.java                # модель пробежки
│       ├── res/                        # layout, строки, темы, иконки
│       └── AndroidManifest.xml
├── gradle/
├── build.gradle.kts

```
